42 school project - HTTP server in C++98

if you see this page it means that:

  • Diana's socket layer accepted your connection and handed it to Client
  • Charlie's Request parser read and validated your HTTP request
  • The Router resolved your URI to the correct location block
  • Handler ran all pre-dispatch checks (isError, 501, 405, conflicting block)
  • handleStatic found the file on disk, read it, and wrote the response
  • Diana's Client sent the raw HTTP response back over the socket
  • Your browser rendered this page
