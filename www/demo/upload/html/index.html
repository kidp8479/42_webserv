webserv - upload demo

webserv: 42 school project - HTTP/1.1 server in C++98

The server accepts raw file uploads via POST. Use curl to test:

curl -X POST http://127.0.0.1:8084/upload/filename.txt --data-binary @yourfile

On success, the server returns 201 Created and saves the file in www/demo/upload/received/.
