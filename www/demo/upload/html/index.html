webserv - upload demo

42 school project - HTTP/1.1 server in C++98

Static upload (C++ handler)

This uses the server's internal upload system.

Test with curl:

curl -X POST http://127.0.0.1:8084/upload --data-binary @yourfile.txt

If successful, the server returns 201 Created and stores the file in:

www/demo/upload/received/
