webserv - upload demo

42 school project - HTTP/1.1 server in C++98

the server accepts raw file uploads via POST. use curl to test:

curl -X POST http://127.0.0.1:8084/upload --data-binary @yourfile.txt

if the upload succeeded, the server returns 201 Created and the file is saved in www/demo/upload/received/.

browser form upload (multipart/form-data) is handled by CGI - not yet implemented.
