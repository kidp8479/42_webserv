42 school project - HTTP server in C++98

I'm a dedicated web page that showcases the static file serving feature

if you see this page, the full request cycle completed successfully:

  • the event loop accepted your TCP connection and handed it to the client handler
  • the request parser read your HTTP request and validated the method, headers, and body
  • the Router resolved your URI to the best matching location block using longest-prefix match
  • the Handler ran all pre-dispatch checks: request validity, method support, method allowed, no conflicting block
  • the static file handler resolved the full path, found the file on disk, detected its MIME type, and built the response
  • the raw HTTP response was sent back over the socket
